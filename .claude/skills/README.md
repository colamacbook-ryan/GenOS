# Kỹ năng chính hãng Anthropic dùng trong repo

Sao chép nguyên bản từ <https://github.com/anthropics/skills> (commit `dbd4588f9e10`, 09/10/2026), giấy phép Apache 2.0 — xem `LICENSE.txt` trong từng thư mục. Không sửa nội dung để còn cập nhật được từ nguồn.

| Kỹ năng | Dùng khi |
|---|---|
| `frontend-design` | Dựng mới hoặc làm lại giao diện (Mặt tiền, Thiết lập, màn Console) |
| `webapp-testing` | Kiểm trên ứng dụng chạy thật bằng Playwright: bấm thử, đọc lỗi console, chụp ảnh 390/1440 |

Kỹ năng có sẵn trong Claude Code dùng kèm: `/code-review` (review trước merge), `/security-review` (khi chạm mã PIN, khoá, quyền, bí mật), `/simplify` (gọn mã sau khi xong gói), `/run` (chạy ứng dụng xem thay đổi).
